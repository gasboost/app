# Changelog

## 0.4.3

- `@gasboost/auth-client` 依存を `^0.8.1` に更新し、`@gasboost/client@0.7.0` との peer 不整合を解消しました。Auth Context と Hook の公開 API は変更していません。

## 0.4.2

- 公開パッケージの `@gasboost/client` 依存を 0.7.0 に更新し、同バージョンの `jobs` を `useAppsScriptJob(jobs)` に渡した際の Job 型の不一致を修正しました。Hook の API と購読・解除の動作は変更していません。
